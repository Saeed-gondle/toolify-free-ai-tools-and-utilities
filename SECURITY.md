# Security Policy — Toolify Studio

## Our Commitment to Security

At [Toolify Studio](https://toolify.studio), security and privacy are core to everything we build.

### Client-Side Processing

Most tools on [Toolify Studio](https://toolify.studio) process data entirely in your browser. Your files, text, and data **never leave your device**. This includes:

- All image tools (compressor, resizer, converter, cropper, background remover)
- All PDF tools (merger, splitter, compressor, editor)
- All developer tools (JSON formatter, regex tester, JWT decoder, hash generator)
- All converter tools (unit, color, number base, epoch)
- All text tools (word counter, case converter, diff checker)

### AI Tools Transparency

AI-powered tools (writing, code generation, image generation) send only the **minimum required text input** to Google's Gemini AI API for processing. No data is stored after the response is returned.

### No Data Collection

- We do not store user files or data
- We do not track tool usage patterns
- We do not sell any user data
- We do not require accounts or personal information

### HTTPS Encryption

All connections to [toolify.studio](https://toolify.studio) are encrypted using TLS/SSL (HTTPS).

## Reporting Security Issues

If you discover a security vulnerability, please report it responsibly:

- **Email**: toolifystudio@duck.com
- **Subject**: Security Vulnerability Report
- **Contact**: [toolify.studio/contact](https://toolify.studio/contact)

We take all security reports seriously and will respond within 48 hours.
